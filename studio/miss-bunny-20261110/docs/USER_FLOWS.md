# Flows
1. Existing root/story → journal; return via header.
2. Journal ZH ⇄ EN preserving topic.
3. Play/pause/seek family and process videos, download MP4/GIF. If unsupported, ordinary download links remain.
4. Open/close art archive; full art links open new tab with noopener.
5. Read/select share captions.
No input, account, payment, persistent state, or third-party data capture. Browser back/refresh use static URLs.
