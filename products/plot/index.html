PLOT｜关系反思、情绪记录与沟通整理

PLOT 帮助你从关系中的疑问出发，整理事实、感受与想表达的话。查看产品定位、使用边界及 PLOT 独立网站。

PLOT 是什么？

PLOT 是自我与关系方向的独立产品。它从关系里的疑问出发，帮助使用者把混在一起的事件、感受、猜测和表达需求分开。重点是看清自己能够观察和选择的部分，而不是替对方宣布答案。

适合的起点可以是：发生了什么、我怎样理解这件事、还缺少哪些信息，以及我想怎样表达。站内介绍不构成心理诊断，不保证判断他人的意图，也不替代现实沟通。实际功能与账户说明在 PLOT 网站查看。

PLOT 会告诉我对方真正怎么想吗？

不会把推测当事实。关系反思应帮助你整理已有信息、辨认不确定性，并决定自己的沟通方式，而不是宣称可以读心。

SAGA 会替我注册或付款吗？

不会。按钮只打开独立网站，请在那里查看功能、账号、价格与隐私说明后再决定。
